排名方法

双信号硬过滤

一个仓库必须同时命中「金融投资信号」（quant / trading / 估值 / 财报 / 量化 / 选股 …）与「Skill 信号」（SKILL.md / agent / claude code / codex …），单靠其中一个词不算。fork、归档仓库、纯链接清单直接排除。

真实 Skill 核验

对头部仓库递归读取 git tree，统计仓库里真实存在的 SKILL.md 数量。空壳仓库的「已核验」一栏会是 0。

趋势分怎么算

以历史快照做差：0.5×7d 日均新增 + 0.3×30d 日均新增 + 0.2×新鲜度。榜单默认按 Stars 排，趋势分作为第二序；也可切「趋势优先」。

数据从哪来

GitHub Search API，每日 UTC 00:10 由 Actions 跑一次；历史快照保留 60–90 天，用于算增量。原始数据开放下载：JSON / CSV。

榜单只做信息聚合，不构成任何投资建议。条目由自动规则生成，可能误收 —— 发现漏收或错收，欢迎在 GitHub 开 issue。
